# MiniBasic
Compilador Mini BASIC em Java

Projecto da cadeira de Compiladores.
Implementacao de um compilador para a linguagem Mini BASIC usando JFlex e Java.

## Estado actual
- Fase 1 — Lexer (CONCLUIDA)
- Fase 2 — Parser (em progresso)



### Requisitos
- Java JDK instalado
- JFlex instalado


## Estrutura
- `lexer/` — Analisador lexico (JFlex)
- `symbols/` — Tabela de simbolos
- `Main.java` — Testes do lexer
